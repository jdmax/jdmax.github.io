James Maxwell develops cryogenic and polarized targets for nuclear physics experiments in the Target Group at Thomas Jefferson National Accelerator Facility, where he has worked since 2015. His work covers dynamically polarized solid targets and the NMR systems that measure them, polarized helium-3 targets at high magnetic field, cryogenics, and the controls software that runs it all.

Polarized Targets & NMR

Dynamically polarized proton and deuteron targets for Jefferson Lab, including the CLAS12 longitudinally polarized target for Run Group C, and the continuous-wave NMR systems that measure their polarization.

Polarized Helium-3

Cryogenics

Refrigerators, cryostats and gas targets: a horizontal 1 K refrigerator for polarized solid targets, the PRad windowless hydrogen gas flow target, and the cryogenic apparatus for the SNS neutron EDM experiment.

EPICS Controls

Slow controls written in Python on pythonSoftIOC, for the Hall B cryotarget, target test stands and the polarized target lab, built on a shared toolkit and driver library.

Papers

  • EPICS for Small-Scale Laboratories with Python Soft IOCsJ. Maxwell, JINST 21 P03030 (2026)

Code

  • softioc_toolkit Framework for soft IOCs: YAML configuration, archiving with a web viewer, state machine, Phoebus displays and an IOC manager.
  • epics-device-lib Shared drivers for Datexel, Lakeshore, Cryomagnetics, AMI, Pfeiffer, MKS, Zaber and more.
  • btarg_controls Controls for the Hall B cryotarget.
  • MEOP_PyIOC Deployment for the MEOP ³He lab: vacuum, temperatures, level, magnet and power supplies.
  • pt-atarg Trial deployment for a Hall A target test stand.
  • pt-ctarg Deployment for a Hall C target test stand.
