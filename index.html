Public Repositories

  • QMeterSim
    Jupyter Notebook simulating the electronic behavior of a series tank Q-meter circuit, modeling RF components and transmission line effects used in continuous-wave NMR measurements.
  • HeSpectra1083
    Calculates the spectrum of ³He and ⁴He near 1083 nm, accounting for Zeeman splitting and Doppler broadening; modernizes existing Fortran code from the Laboratoire Kastler Brossel at ENS Paris.
  • DeuteronPeakFit
    Python fitting routine for spin-1 NMR signals with quadrupolar splitting, extracting polarization measurements from continuous-wave NMR data via non-linear least-squares minimization.
  • rgc_offline
    Offline analysis of experimental data from polarized proton and deuteron targets at Jefferson Lab, processing NMR event data to compute calibration constants and polarization values.
  • He3_LCR_Polarimeter
    LabView software controlling a ³He polarimeter that uses liquid crystal retarders for polarization measurement, developed at MIT.
